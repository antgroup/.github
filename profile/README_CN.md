# 蚂蚁集团 🩷 开源社区

🌐️ [English](README.md) | 中文

蚂蚁集团起步于 2004 年诞生的支付宝，源于一份为社会解决信任问题的初心，经过近二十年的发展，已成为世界领先的互联网开放平台。我们致力于将技术普惠到开源社区，一直伴随开源社区的成长。

蚂蚁集团热爱开源，积极参与开源社区建设，正如我们的愿景所言『构建未来服务业的数字化基础设施，为世界带来更多微小而美好的改变』，也希望能够给开源社区带来微小的改变和贡献。

以下是我们蚂蚁集团开源推出的开源项目列表，覆盖我们所触及的多个方面和领域：

## 人机交互

- <img src="https://github.com/ant-design.png?size=16" width="16" height="16" alt="Ant Design"> **[Ant Design](https://github.com/ant-design/ant-design)** — 企业级设计语言和 React UI 组件库，提供丰富的高质量组件、可预测的 TypeScript 静态类型，以及灵活强大的 CSS-in-JS 主题定制能力。

- <img src="https://github.com/antvis.png?size=16" width="16" height="16" alt="AntV"> **[AntV](https://github.com/antvis)** — 蚂蚁集团发起的新一代数据可视化解决方案，涵盖统计、关系、地理和非结构化数据可视化，并提供 AI 驱动的智能可视化能力。

- <img src="https://github.com/umijs.png?size=16" width="16" height="16" alt="Umi"> **[Umi](https://github.com/umijs/umi)** — 基于路由的可扩展企业级前端应用框架，拥有覆盖从源码到构建产物全生命周期的插件体系，已服务蚂蚁集团 10,000 多个应用。

- <img src="https://github.com/eggjs.png?size=16" width="16" height="16" alt="Egg"> **[Egg](https://github.com/eggjs/egg)** — 基于 Node.js 和 Koa 的框架开发框架，提供内置进程管理、插件体系及面向生产应用的企业级定制能力。

## 人工智能

- <img src="https://github.com/eosphoros-ai.png?size=16" width="16" height="16" alt="DB-GPT"> **[DB-GPT](https://github.com/eosphoros-ai/DB-GPT)** — 面向新一代 AI + Data 产品的开源智能数据助手，连接数据库、数据仓库和知识库，并可在沙箱环境中自主编写 SQL 和代码。

- <img src="https://github.com/codefuse-ai.png?size=16" width="16" height="16" alt="CodeFuse"> **[CodeFuse](https://github.com/codefuse-ai)** — 开发代码大语言模型（Code LLM），支持并增强 AI 原生软件开发全生命周期，涵盖设计、编码、测试、部署、运维和洞察分析。

- <img src="https://github.com/antgroup.png?size=16" width="16" height="16" alt="VSAG"> **[VSAG](https://github.com/antgroup/vsag)** — 向量索引库，可针对不同规模的向量集合进行高效相似性搜索，为 AI/ML 检索和 RAG 工作负载提供支持。

- <img src="https://github.com/agentuniverse-ai.png?size=16" width="16" height="16" alt="agentUniverse"> **[agentUniverse](https://github.com/agentuniverse-ai/agentuniverse)** — 大语言模型多智能体框架，提供灵活的智能体组件和丰富的协作模式（PEER/DOE），便于融入领域专业知识；源于蚂蚁集团金融业务实践。

## 分布式计算

- <img src="https://github.com/sofastack.png?size=16" width="16" height="16" alt="SOFAStack"> **[SOFAStack](https://github.com/sofastack)** — 可扩展开放金融架构技术栈，由一系列云原生中间件组件组成，旨在构建高性能、高可靠的分布式系统，并经过关键金融场景验证。

- <img src="https://github.com/kata-containers.png?size=16" width="16" height="16" alt="Kata Containers"> **[Kata Containers](https://github.com/kata-containers/kata-containers)** — 轻量级虚拟机，兼具容器般的体验和性能，同时提供虚拟机级别的工作负载隔离与安全优势；兼容 OCI，支持多种虚拟机监控程序和架构。

- <img src="https://github.com/oceanbase.png?size=16" width="16" height="16" alt="OceanBase"> **[OceanBase](https://github.com/oceanbase/oceanbase)** — 面向 AI 时代的统一分布式数据库，开源、多模型，以单一引擎支持严苛工作负载，可透明扩展至 1,500 节点和 PB 级数据，并兼容 MySQL。

- <img src="https://github.com/tugraph-family.png?size=16" width="16" height="16" alt="TuGraph"> **[TuGraph](https://github.com/TuGraph-family/tugraph-db)** — 蚂蚁集团与清华大学共同研发的高性能图数据库，支持大规模、低延迟图分析，具备 TB 级容量、完整 ACID 事务和 HTAP 能力。

## 可信原生安全

- <img src="https://github.com/antgroup.png?size=16" width="16" height="16" alt="YASA"> **[YASA](https://github.com/antgroup/YASA-Engine)** — 开源静态程序分析框架，其核心创新是统一抽象语法树（UAST），支持多种编程语言，可进行精确的 AST 查询、数据流分析和自定义检查。

- <img src="https://github.com/secretflow.png?size=16" width="16" height="16" alt="SecretFlow"> **[SecretFlow](https://github.com/secretflow/secretflow)** — 隐私保护数据分析与机器学习统一框架，通过分层抽象设备架构支持 MPC、FL、TEE、HE 和 DP。

- <img src="https://github.com/asterinas.png?size=16" width="16" height="16" alt="Asterinas"> **[Asterinas](https://github.com/asterinas/asterinas)** — 使用 Rust 编写的生产级 Linux 兼容操作系统内核，率先采用 framekernel 架构，将不安全 Rust 限制在小型、可审计的框架中，以实现内存安全与高性能。

- <img src="https://github.com/tongsuo-project.png?size=16" width="16" height="16" alt="Tongsuo"> **[Tongsuo](https://github.com/Tongsuo-Project/Tongsuo)** — 开源密码学库，提供现代密码算法和安全通信协议（SM2/SM3/SM4/ZUC 及后量子密码），并获得商用密码产品认证。

- <img src="https://github.com/occlum.png?size=16" width="16" height="16" alt="Occlum"> **[Occlum](https://github.com/occlum/occlum)** — 使用 Rust 编写的 Intel SGX 内存安全、多进程库操作系统（LibOS），可让未经修改的应用运行于 SGX enclave 中，透明地保护机密性和完整性。
