# Ant Group 🩷 Community

🌐️ English | [中文](README_CN.md)

Ant Group, the leading supplier of online financial services in China, has been involved in open-source initiatives since it was founded. We continually encourage the growth of open-source communities.

Ant Group offers high value to open-source communities. According to our vision, "Create future-ready digital infrastructure for the service industry, and bring small and beautiful changes to the world." We also aspire to make small contributions and changes to open-source communities.

The Ant Group is committed to open source and has released numerous kinds of projects, which are included below.

## Human-Computer Interaction

- <img src="https://github.com/ant-design.png?size=16" width="16" height="16" alt="Ant Design"> **[Ant Design](https://github.com/ant-design/ant-design)** — An enterprise-class UI design language and React UI library that ships a comprehensive set of high-quality components with predictable static types in TypeScript and powerful CSS-in-JS theme customization.

- <img src="https://github.com/antvis.png?size=16" width="16" height="16" alt="AntV"> **[AntV](https://github.com/antvis)** — A new generation of data visualization framework initiated by Ant Group, covering four series (statistical, graph, geographical and unstructured visualization) and AI-powered intelligent visualization.

- <img src="https://github.com/umijs.png?size=16" width="16" height="16" alt="Umi"> **[Umi](https://github.com/umijs/umi)** — An extensible enterprise-level front-end application framework based on routing, with a plugin system covering the full lifecycle from source code to build artifacts; has served 10,000+ applications at Ant Group.

- <img src="https://github.com/eggjs.png?size=16" width="16" height="16" alt="Egg"> **[Egg](https://github.com/eggjs/egg)** — A web framework's framework for Node.js & Koa, featuring built-in process management, a plugin system and enterprise-grade customization for production applications.

## Artificial Intelligence

- <img src="https://github.com/eosphoros-ai.png?size=16" width="16" height="16" alt="DB-GPT"> **[DB-GPT](https://github.com/eosphoros-ai/DB-GPT)** — An open-source agentic AI data assistant for the next generation of AI + Data products, connecting databases, warehouses and knowledge bases, and writing SQL/code autonomously in sandboxed environments.

- <img src="https://github.com/codefuse-ai.png?size=16" width="16" height="16" alt="CodeFuse"> **[CodeFuse](https://github.com/codefuse-ai)** — Develops Code Large Language Models (Code LLMs) to support and enhance full-lifecycle AI-native software development, covering design, coding, testing, deployment, operations and insight analysis.

- <img src="https://github.com/antgroup.png?size=16" width="16" height="16" alt="VSAG"> **[VSAG](https://github.com/antgroup/vsag)** — A vector indexing library used for efficient similarity search across vector sets of various sizes, powering AI/ML retrieval and RAG workloads.

- <img src="https://github.com/agentuniverse-ai.png?size=16" width="16" height="16" alt="agentUniverse"> **[agentUniverse](https://github.com/agentuniverse-ai/agentuniverse)** — An LLM multi-agent framework providing flexible agent components and rich collaborative patterns (PEER/DOE) to integrate domain expertise; originated from Ant Group's financial business practices.

## Distributed Computing

- <img src="https://github.com/sofastack.png?size=16" width="16" height="16" alt="SOFAStack"> **[SOFAStack](https://github.com/sofastack)** — Scalable Open Financial Architecture Stack: a collection of cloud-native middleware components designed to build distributed systems with high performance and reliability, validated by mission-critical financial scenarios.

- <img src="https://github.com/kata-containers.png?size=16" width="16" height="16" alt="Kata Containers"> **[Kata Containers](https://github.com/kata-containers/kata-containers)** — Lightweight virtual machines that feel and perform like containers, but provide the workload isolation and security advantages of VMs; OCI-compatible and supports multiple hypervisors and architectures.

- <img src="https://github.com/oceanbase.png?size=16" width="16" height="16" alt="OceanBase"> **[OceanBase](https://github.com/oceanbase/oceanbase)** — A unified distributed database for the AI era — open-source, multi-model, one engine for the most demanding workloads with transparent scalability to 1,500 nodes / PB-scale data and MySQL compatibility.

- <img src="https://github.com/tugraph-family.png?size=16" width="16" height="16" alt="TuGraph"> **[TuGraph](https://github.com/TuGraph-family/tugraph-db)** — A high-performance graph database developed by Ant Group and Tsinghua University, delivering large-scale, low-latency graph analysis with TB-scale capacity, full ACID transactions and HTAP capabilities.

## Trust Native Security

- <img src="https://github.com/antgroup.png?size=16" width="16" height="16" alt="YASA"> **[YASA](https://github.com/antgroup/YASA-Engine)** — An open-source static program analysis framework whose core innovation is a Unified Abstract Syntax Tree (UAST) that supports multiple programming languages and enables accurate AST queries, data-flow analysis and custom checkers.

- <img src="https://github.com/secretflow.png?size=16" width="16" height="16" alt="SecretFlow"> **[SecretFlow](https://github.com/secretflow/secretflow)** — A unified framework for privacy-preserving data analysis and machine learning, supporting MPC, FL, TEE, HE and DP through a layered abstract-device architecture.

- <img src="https://github.com/asterinas.png?size=16" width="16" height="16" alt="Asterinas"> **[Asterinas](https://github.com/asterinas/asterinas)** — A production-grade Linux-compatible OS kernel written in Rust, pioneering the framekernel architecture that confines unsafe Rust to a small auditable framework for memory safety and high performance.

- <img src="https://github.com/tongsuo-project.png?size=16" width="16" height="16" alt="Tongsuo"> **[Tongsuo](https://github.com/Tongsuo-Project/Tongsuo)** — An open-source cryptographic library providing modern cryptographic algorithms and secure communication protocols (SM2/SM3/SM4/ZUC + post-quantum), with commercial cryptographic product certification.

- <img src="https://github.com/occlum.png?size=16" width="16" height="16" alt="Occlum"> **[Occlum](https://github.com/occlum/occlum)** — A memory-safe, multi-process library OS (LibOS) for Intel SGX, written in Rust, enabling unmodified applications to run inside SGX enclaves to protect confidentiality and integrity transparently.
